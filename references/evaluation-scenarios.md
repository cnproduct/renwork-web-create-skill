# 行为评测：选择是否更好，领域是否误用

仅在优化/验证本 Skill 时读取。结构合法不证明真实任务效果；保留原始输入和产物，比较具体判断。生成方只得到任务、Skill、原始资料，不给预期答案或旧/新对照结果。

## 可复用的四类场景

| 场景 | 输入与任务 | 检查实际结果 |
| --- | --- | --- |
| 复刻前选型 | 同品类十站资料，包含大流量零售、相关搜索入口、技术文档、不同市场/周期/渠道指标及不完整AI采样 | 先选细分方向与采购任务；十站有取舍；不同维度选不同学习职责；只在可比范围内排序；请求失败不算未引用 |
| 非网站 Skill | CSV→JSON 把 `001` 变成 `1`，缺失金额变成 `0` | 定位转换契约和根因，保留标识符与缺失语义；最小改动与边界样例；不套SEO、贸易或Top10网站 |
| 不适用来源 | 上游宣称全球第一、固定企业产能/认证、增加端点即可有AI流量；没有相应原始证据 | 保留适用方法，剔除无依据结论；目标参数不能从标杆继承；指出验证缺口 |
| 证据不足与范围边界 | 只有计划/成功叙述、只能读取部分页面、仅有三站；或只要求忠实复刻/局部修改 | 不升级为已验证成功、不凑十站、不称全站完成；记录暂定/未测，继续可完成范围；保持用户指定范围 |

跨行业建站还应在真实任务中检查石材、卫浴和工业电子是否形成不同买家任务与视觉表达。这些是后续项目场景，未执行不得预先记为 PASS。

## 本次离线对照

原始模拟输入、任务、新旧产物和哈希保存在 [评测记录](../evals/discovery-v4.json)。示例域名均为 `.example`，不是真实市场数据，不用于任何网站宣传。

条件：同一父会话模型设置、两个无历史上下文的独立执行代理，各读取指定版本及同一份离线资料，禁止联网和外部动作；每版一轮，网站决策上限1200中文字、转换方案500中文字。基线为 v3 `0b6feeffc6b6cc86bc8d3ae076f4c0e0186d8169`，候选版本为合并后的 v4.2.0（精确文件哈希见记录）。这是前向决策/方案检查，不是全球排名研究、真实CSV修复、网站部署或增长实验。

评价关注具体决策而非是否复述章节。相同案例下旧版同样做对的部分应如实保留；一轮对照不能估计普遍提升率。未测设计、真实流量、收录、AI引用变化、RFQ收件及多次运行稳定性。

实测观察：两版都选择澳大利亚户外石灰石、区分买家角色，只比较 B/C 的同口径目录自然搜索估算；AI 引用均使用 6 个有效样本，保留 2 次失败并单列另一平台提及；均拒绝无证据产能与流量保证。新版额外形成明确的十域取舍表、A/B/C/E 四职责融合和 PROVISIONAL 状态。旧版在 CSV 任务说明自己是建站 Skill 后给出通用修复方案，新版直接路由内置优化模式；两版都没有虚报实际修复。
